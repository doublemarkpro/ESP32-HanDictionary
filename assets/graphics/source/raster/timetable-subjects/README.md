# Timetable subject icons

These transparent PNG masters were created with the built-in OpenAI image generation tool on
2026-09-15, then trimmed and reduced to 256 x 256 for source control. `tools/ui-assets/timetable-assets.cjs`
converts them into the compact 48 x 48 PNG resources embedded by the Tab5 firmware.

Shared prompt:

> Create one square app icon asset for a premium children's learning assistant timetable on a
> warm ivory UI. Cute polished 3D clay-and-paper illustration, soft pastel colors, rounded friendly
> shapes, subtle highlights and depth, crisp silhouette readable at 40x40 pixels. Isolated single
> object centered with generous transparent padding. Transparent background, no tile, no circle,
> no border, no letters, no words, no numbers, no watermark. Consistent with a refined green,
> coral, sky-blue, lavender, and golden classroom icon family.

The subject suffixes requested an open storybook, calculator, abstract alphabet blocks, science
flask, art palette, running child, computer, musical notes, martial-arts child, watering can and
trowel, recorder flute, elective star, and school-club group respectively.
