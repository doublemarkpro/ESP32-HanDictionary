# Product assets

- `source/icon-*.svg`: original product icons, created for this project, generated by `tools/ui-assets/generate.cjs` under the project license. PNG versions are transparent 128×128 renders.
- UI fonts: Source Han Sans SC and DejaVu Sans from the pinned LVGL dependency. Converted subsets in `main/han_dictionary/assets`, original license notices in `licenses/`. Source fonts remain unmodified in `managed_components`; normal firmware builds use committed generated C and require no npm setup.
- `source/strokes/89C4.json`: unmodified 规 stroke paths from [Hanzi Writer Data](https://github.com/chanind/hanzi-writer-data/blob/master/data/%E8%A7%84.json), which derives from Make Me A Hanzi and Arphic fonts. Copyright (C) 1999 Arphic Technology Co., Ltd.; ARPHIC PUBLIC LICENSE in `licenses/ARPHICPL.TXT`.
- `source/strokes/77E9.json`: unmodified 矩 paths from [Hanzi Writer Data](https://github.com/chanind/hanzi-writer-data/blob/master/data/%E7%9F%A9.json), under the same ARPHIC PUBLIC LICENSE. The SD preparation script creates cumulative highlighted frame derivatives; these remain under that license and do not supply dictionary definitions or printed pages.
- `source/strokes/gui-*.png` and `main/han_dictionary/assets/han_strokes.c`: derivatives rendered on 2026-09-11 as eight cumulative frames, highlighting the active stroke. These derivatives remain under ARPHIC PUBLIC LICENSE and carry no warranty. The original paths and conversion script are included; these assets are independent of the application source license.

Regeneration (after ESP-IDF has fetched managed components):

```
cd tools/ui-assets
npm ci
node generate.cjs
```

Font subsets are collected from the feature's C++ source and include Latin/IPA ranges. Add a label to source, then regenerate. Full arbitrary dictionary glyph coverage remains a later content-font extension; the embedded 规 glyph and current UI/IPA are covered.

UI2 also collects starter dictionary entry text and U+03B8 (theta), uses lossless 4 bpp font compression, and enables the matching decoder only in the product builds. `prepare-resources.cjs --output <new-directory>` generates 44 outlined IPA SVG/PNG cards, an audio-path catalog, and SD stroke frames. The cards are visual resources, not bundled pronunciations. Font and stroke notices accompany the pack; third-party custom inputs must retain their own permission notices.
