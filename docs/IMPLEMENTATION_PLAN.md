# 小小助手 UI 第一轮实施

目标：把已确认设计转为 Tab5 可编译、可触摸操作的产品 UI，并建立可离线使用、可换电脑构建的资源管线。

## 本轮交付

- [x] 六入口横屏主页、返回导航、真实状态栏、持续可见的小智提示；未接通电量显示未知。
- [x] 中文 UI 字体子集、IPA 字体、六个图标和素材生成工具。
- [x] 查字服务共享结构、本地示例、SD 字条导入、明确的第 12 版页码状态。
- [x] 查字结果导航、规字笔顺控制、17 张音标卡和 SD 发音接口（录音素材待导入）。
- [x] SD SPI 挂载代码、缺卡降级、内容包验证及准备脚本；物理读卡待验收。
- [x] 作业分科计时和持久化、课程表/单个每日提醒/天气缓存页面。
- [x] 主机测试、两个芯片版本编译、分区容量检查、交付文档与 GitHub 同步。

## 第一轮边界

本轮允许未来功能显示真实的空状态，但不得填入假课程、假天气、假页码或把未接通的按钮显示为成功。完整新华字典第 12 版数据和教学发音内容需有可使用的数据源；资源缺失不阻止主页和内置示例运行。录音评分、RTC 关机唤醒、在线天气服务、完整字库字体和完整笔顺扩展独立迭代。

用户已确认：商务印书馆《新华字典》第 12 版单色本，ISBN `978-7-100-16807-6`。导入与固件查询按该 ISBN 核验页码；目前示例页码为 null。

联网首轮使用手机配网而非触屏键盘；计时保存本次作业而非每日历史；闹钟依赖开机且系统时间同步。实际截图在 [ui/rendered](ui/rendered/)，不是之前的概念稿。字体生成源及许可证均已保留，普通固件构建无需重新生成。

## 存储分工

| 内部 Flash / NVS | microSD（FAT32） |
| --- | --- |
| 固件、启动与 UI 字体、小图标、规字示例 | 版本化字典条目、页码映射、后续完整笔顺和字形 |
| Wi-Fi 设置、本地计时、闹钟设置 | 音标单音/例词音频、课程表、天气缓存 |

设备无卡可进入主页和内置示例；缺失内容明确提示。SD 挂载失败不格式化、不覆盖用户数据，启动挂载完成后读取内容；本轮不承诺热插拔。

## 数据与硬件依据

- [商务印书馆第12版](https://www.cp.com.cn/xinhua12/)：纸书与 App 配套，未发现公开可再分发的完整离线数据包。
- [商务印书馆大字本](https://www.cp.com.cn/book/9c3b015f-5.html)：第12版存在不同纸书形式，页码按 ISBN/版式核验，未知填 null。
- [M5Stack microSD 示例](https://docs.m5stack.com/en/arduino/m5tab5/microsd)：采用 SPI，CS42、SCK43、MOSI44、MISO39；不占用 Wi-Fi 的 SDIO 总线。

## 真机验收

2026-09-11 已完成 69 项 Python 主机测试，以及实际 LVGL 页面模拟器检查（导航、音标分类、笔顺前后步、返回后继续计时、字条解析、错误 ISBN/路径拒绝）。两种产品固件均使用 ESP-IDF 6.0.2 编译通过：

| 变体 | 应用大小 | 5 MiB 应用分区剩余 |
| --- | --- | --- |
| Legacy | `0x46cd40` 字节 | `0x932c0` 字节，约 11.5% |
| P4X | `0x472940` 字节 | `0x8d6c0` 字节，约 11.0% |

另已回归编译未启用产品 UI 的原版 `m5stack-tab5-p4x`（应用 `0x38e320` 字节），确认该变体仍使用原有应用分区。未改动共用协议和其他显示类型；其物理设备未测试。许可文本保留上游原始空白，字体 C 文件保留转换工具输出格式。

独立烧录包在本机 `dist/firmware/ui1-Legacy`、`dist/firmware/ui1-P4X`；示例卡目录为 `dist/sdcard-starter/handict`。这些生成输出不提交 Git，回家可按脚本重新生成。首次分区布局迁移需要完整串口刷机，不能只 OTA 应用。

两种固件可编译不等于真机验证。到家确认芯片版本、LCD/触摸版本，验证横屏四角、无卡/有卡启动、联网、语音中断、笔顺、计时返回不停止、重启恢复、SD 发音与拔卡错误。保留串口日志。
