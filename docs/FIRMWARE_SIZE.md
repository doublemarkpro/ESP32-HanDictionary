# 固件为什么约 4.4 MiB？

2026-09-11，以本机实际 `.bin`、链接 map 和 ESP-IDF size 输出为准。

## 不是一个界面占了 4 MB

这是完整的小智语音固件加学习工具，并非只包含一张主页。已经链接音频编解码、语音处理、
联网协议、TLS / 加密、P4 与 C6 通信、硬件驱动、LVGL、字体和产品逻辑。
正常构建只选一个板型，不是把小智支持的所有开发板都打包进去。

| P4X 应用二进制 | 字节 | 相比前一轮 |
| --- | ---: | ---: |
| UI2：基础页面 | 4,370,752 | — |
| UI3：主页圆体 / 精修图片 / 状态栏 | 4,567,184 | +196,432（191.8 KiB） |
| UI4：课程表 / 字形 / 小图标 / 查询缓存 | 4,618,240 | +51,056（49.9 KiB） |

“主页约 192 KiB”指上一轮**整体改动的增量**，不是主页全部资源的独立大小。
同样，UI4 增量包含通用字体增加的汉字、新的 32 px 粗圆体、课程表控件与 MCP 查询，
不仅是六个小图标。六张图标 PNG 本身只有 4,226 字节。

## 链接进去的资源有哪些

UI4 P4X 的 `esp_idf_size --files --format json2` 输出，以下是选取的链接对象大小，
不是源文件字符数，也不是运行堆内存；该表不覆盖全部固件，不能据此简单相加还原 `.bin`。

| 对象 / 组 | 链接对象大小（字节） |
| --- | ---: |
| 产品全部已链接字体子集（28 / 40 / IPA大字 / 五个圆体子集） | 448,819 |
| `home_skin.c`（主页图片、状态图标、底部背景等） | 171,413 |
| `han_strokes.c`（内置规字的八帧笔顺） | 100,935 |
| `han_display.cc`（所有产品页面代码） | 52,236 |
| `timetable_assets.c`（新小图标和描述符） | 4,394 |

此外，UI3 基线按链接节剔除 BSS / noinit 后，LVGL 约 358 KiB、小智原有字体约 275 KiB、
音频编解码库约 193 KiB、语音模型计算库约 204 KiB；联网、加密、驱动等还在其他组件中。
这些是说明组成的量级，不是功能开关关闭后能保证省下的体积；有共享依赖和链接字符串合并。
例如链接器可能把合并字符串池归到第一个对象名下，不能误把整池都当成该文件自己的逻辑。

仓库里的完整 TTF、设计图、SVG、完整图形包、十六进制 C 文本以及带调试信息的 `.elf` / `.map`
都不等于烧入 Flash 的大小。完整圆体 TTF 仅用于生成，固件实际只嵌入小字形子集。

## “快满了”是哪块空间

固件配置 16 MiB Flash，分区没有在 UI4 改动：

| 用途 | 容量 | 当前使用 / 说明 |
| --- | ---: | --- |
| 活动应用 OTA 槽 | 5 MiB | P4X 使用 4,618,240 字节，余 624,640 字节（11.9%，610 KiB） |
| 备用应用 OTA 槽 | 5 MiB | 为升级保留；不是额外字典储存区 |
| 小智资源区 | 6,160,384 字节 | 使用 2,985,897 字节，余 3,174,487 字节（约 3.03 MiB） |
| 其余空间 | 分区表定义 | 引导、NVS、OTA 状态等 |

因此应用槽接近九成，不意味着整个 16 MiB Flash 已写满。
资源区剩余空间也不能直接变成应用槽空间。更改布局涉及完整刷机与 OTA 兼容，不能随意挪动。
32 MiB PSRAM 是运行内存，与 Flash 容量不同；真实空闲量、最大连续块与流畅度待硬件测量。

## 后续怎么控制

本轮采用真实表格 + 复用背景 + 40 px 小图标，没有把设计图作为整屏大位图嵌入。
字体继续保留 4 bpp 无损压缩。构建脚本仍强制应用至少保留 512 KiB，UI4 通过这一门槛，
但离门槛只剩约 100 KiB 的增量预算，**不代表后续所有功能都能不加限制地放进去**。

后续应优先评估重复字体和实际不使用的组件；大规模字库、录音、笔顺、天气插画按需放 SD。
移动 PNG 到小智资源分区也是可评估路径，但需要资源加载代码，不会仅移动文件就自动生效。
本轮没有为了缩小体积擅自删掉语音、联网、OTA 或改动分区布局。

复核命令（先运行 `./tools/setup.ps1`，当前构建必须是目标板型）：

```powershell
python tools/capacity_report.py
python -m esp_idf_size --archives build/xiaozhi.map
python -m esp_idf_size --files --format json2 -o build/size-files.json build/xiaozhi.map
```

当前 ESP-IDF size 对 P4 输出 `sram_seg` 类型映射警告；不要把其“External RAM”分组当成
运行 RAM 使用实测。应用容量检查独立使用 `.bin` 文件实际长度和分区 CSV。
