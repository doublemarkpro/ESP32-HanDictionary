# 全屏翻页时钟：设计与待办

状态：**待实现**。本页记录已确认的视觉稿与交互要求，不代表固件已经具备该功能。

## 已确认设计

![全屏翻页时钟设计稿](flip-clock-preview/flip-clock-concept-v2.png)

- 从主页点击顶部时间进入，作为独立的全屏时间展示页面。
- 页面主体只显示时、分、秒；左上角保留统一返回按钮。
- 时钟下方显示公历年月日、星期和农历信息。设计稿中的日期仅为排版示例，实际显示必须读取设备当前日期。
- 延续天气、字典和设置页面的柔和背景、深蓝主色及大字号风格。
- 不显示标题、状态栏、天气、语音入口或其他操作按钮，避免干扰时间阅读。

## 动效与交互待办

- [ ] 在主页顶栏时间区域增加点击入口，并保持原有时间刷新与其他顶栏交互正常。
- [ ] 新增全屏翻页时钟页面及统一返回路径。
- [ ] 实时显示 `HH:MM:SS`，补零并使用 24 小时制。
- [ ] 秒钟每秒执行一次翻页；分钟和小时只在进位时翻页。
- [ ] 翻页建议总时长约 300 ms：旧数字上半页向内翻下，再展开新数字下半页。
- [ ] 使用轻微明暗和透视表达翻页，不绘制突兀的黑色中心横线。
- [ ] 显示公历年月日、星期及农历年月日；日期跨日时自动刷新。
- [ ] 页面进入、退出及动画过程中不阻塞 LVGL、主事件循环或音频任务。
- [ ] 禁止声音反馈；时钟页面及调试过程保持静音。
- [ ] 在桌面模拟器检查布局和动效，再在 Tab5 真机验证帧率、触摸返回、跨分钟及跨日更新。

## 验收标准

- 六位数字在 1280×720 横屏中保持水平居中、间距一致，没有裁切或跳位。
- 静止状态数字清晰；翻页时只改变需要进位的数字卡片。
- 日期信息位于时钟正下方，层级弱于时间但在正常观看距离下可读。
- 从主页点击时间能够稳定进入，点击返回按钮能够立即回到主页。
- 连续运行不会出现累计计时漂移、动画重叠或明显内存增长。
